About StockVision AI

A Machine Learning powered Stock Analytics Platform built with Flask.

Project Overview

StockVision AI is a modern web application that combines Financial Analytics, Machine Learning, Interactive Visualization and Portfolio Management into one platform.

It enables users to analyze stocks, visualize market trends, generate AI-based price predictions and monitor investment portfolios using real market data.

Technology Stack

Python
Flask
Scikit-learn
Plotly

Yahoo Finance

Key Features

  • Live Stock Market Data
  • Interactive Plotly Charts
  • Technical Indicators
  • Machine Learning Predictions
  • Portfolio Tracking
  • Risk Analysis
  • Historical Price Analysis
  • Modern Responsive UI
